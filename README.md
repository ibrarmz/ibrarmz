## ✦ Proyecto destacado: IBRÆ

<a href="https://github.com/ibrarmz/ibrae"><img src="https://raw.githubusercontent.com/ibrarmz/ibrae/main/docs/demo.gif" alt="IBRÆ: la isla dinámica en el escritorio" width="100%"></a>

**[IBRÆ](https://github.com/ibrarmz/ibrae)** · *A different layer of your desktop.* Una isla dinámica para **Windows y Linux**: música, lo que hace Claude Code (y contestar sus permisos sin ir a la terminal), calendario, focus, notas y sistema, en una píldora arriba de tu pantalla. Gratis, open source (MIT) y con actualizaciones automáticas.

`Tauri 2` · `Rust` · `Svelte 5` · ~0 % CPU en reposo

**[⬇ Descargar](https://github.com/ibrarmz/ibrae/releases/latest)** · **[⭐ Ver el repo](https://github.com/ibrarmz/ibrae)** · **[♥ Apoyar](https://github.com/sponsors/ibrarmz)**
